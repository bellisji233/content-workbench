# 内容状态覆盖表

工作台默认从文件和平台数据推断每篇内容的状态。这张表只用来标例外，没写的走自动推断。
页面上点状态按钮改的状态存在工作台里，不写回这张表；这张表适合批量预填或长期固定的例外。

## 状态取值

| 状态 | 含义 |
|---|---|
| `生产中` | 还在做 |
| `待发布` | 做完了还没发 |
| `主动停掉` | 决定不做了 |
| `效果不好` | 做出来了但不发 |
| `归档` | 不再处理，留档 |

## 覆盖表

key 用流水线的文件夹名，或稿件文件名（不含 .md、去掉日期前缀）。

| key | 状态 | 备注 |
|---|---|---|
